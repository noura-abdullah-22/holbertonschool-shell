# Shell, basics

This directory contains basic shell scripts for the Holberton School Shell basics project.

| Script | Description |
|---|---|
| `0-current_working_directory` | Prints the absolute path of the current working directory |
| `1-listit` | Lists the contents of the current directory |
| `2-bring_me_home` | Changes the working directory to the user's home directory |
| `3-listfiles` | Lists the current directory in long format |
| `4-listmorefiles` | Lists the current directory in long format, including hidden files |
| `5-listfilesdigitonly` | Lists the current directory in long format, including hidden files, with numeric user and group IDs |
| `6-firstdirectory` | Creates the directory `my_first_directory` in `/tmp/` |
| `7-movethatfile` | Moves the file `betty` from `/tmp/` to `/tmp/my_first_directory` |
| `8-firstdelete` | Deletes the file `betty` from `/tmp/my_first_directory` |
| `9-firstdirdeletion` | Deletes the directory `/tmp/my_first_directory` |
| `10-back` | Changes the working directory to the previous one |
| `11-lists` | Lists all files in the current directory, its parent, and `/boot`, in long format |
| `12-file_type` | Prints the type of the file `/tmp/iamafile` |
| `13-symbolic_link` | Creates a symbolic link to `/bin/ls` named `__ls__` in the current directory |
| `14-copy_html` | Copies HTML files to the parent directory if they are new or newer there |
| `15-lets_move` | Moves all files starting with an uppercase letter to `/tmp/u` |
| `16-clean_emacs` | Deletes all files in the current directory that end with `~` |
| `17-tree` | Creates the directories `welcome/`, `welcome/to/` and `welcome/to/school` |
